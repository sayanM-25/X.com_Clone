# X.com Clone

This project is a front-end clone of **X (formerly Twitter)**, built to practice modern UI development and styling.

## 🚀 Installation & Setup

### Prerequisites
- Node.js (Download from https://nodejs.org/)

### Steps

1. Install project dependencies:
   ```bash
   npm install
2. Build Tailwind CSS (watch mode):
   ```bash
   npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --watch
   ```
   OR
   ```bash
   npm run build
3. Open index.html using a live server (VS Code Live Server recommended).
